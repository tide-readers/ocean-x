# ocean-x

The digital artifact for our immersive experience. Built by the Hyper Island MA class, working as one team, with Claude Code.

**Live:** https://ocean-x.tidereaders.org (also https://ocean-x-eight.vercel.app)

## How it fits together

- Talk: Slack workspace "Tide Readers"
- Work and presentation: the class Miro board
- Code: this repo
- Hosting: Vercel, deploys `main` on every merge

## Working on it

1. Clone the repo and open it in Claude Code (or your editor).
2. Make a branch, change things in `public/`, open `public/index.html` in a browser to check.
3. Open a pull request. When it is merged to `main`, Vercel publishes it within a minute.

Conventions and context for Claude Code are in `CLAUDE.md`.
